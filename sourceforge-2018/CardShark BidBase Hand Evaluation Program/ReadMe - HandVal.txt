CardShark BidBase Hand Valuation is intended to be an improvement over the Goren point
count system (4-3-2-1). It is based on the best of Goren, COBRA, Fifths, KNR, Pavlicek,
and TSP.  Any of these systems or the BidBase system can be specified in Bid entries.
You can review or modify any of these systems or create your own system using this
program.

See www.aeyec.com/BidBase for documentation for this and other BidBase programs.

IMPORTANT:

The BidBase programs are written in Visual Basic 6.

At this time, this distribution is intended for people who have Visual Basic installed.
The BidBase programs work but still have a few minor features to be added and/or more
testing to insure that all errors have been trapped.

Mostly, the programs need to be packaged into an installer which will install all
necessary References and Components in a way which will allow the programs to work
in Windows 10.

BidBaseDB is a DLL which accesses the BidBase database to find bids for hands.
It has its own folder on SourceForge, along with the BidBase database.
