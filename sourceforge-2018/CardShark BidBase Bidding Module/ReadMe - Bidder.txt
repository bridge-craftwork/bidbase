CardShark BidBase Bidding Module ("Bidder") is VB6 source code for a DLL which can
be used by other programs to find bids giving specifications for a bridge hand.
The Bidder gets the specifications from client programs and returns the bid.
It requires the BidBaseDB bidding database which is also in this folder.

Bid entries can be edited or added in the BidBase Editor program which is also
available on the BidBase page on SourceForge.

The files in BidBaseDBTest.ZIP are VB6 source code for an example of how to get
a bid from the module.

The documentation for this and all the rest of BidBase are at www.aeyec.com/BidBase.

IMPORTANT:

The BidBase programs are written in Visual Basic 6.

At this time, this distribution is intended for people who have Visual Basic installed.
The BidBase programs work but still have a few minor features to be added and/or more
testing to insure that all errors have been trapped.

Mostly, the programs need to be packaged into an installer which will install all
necessary References and Components in a way which will allow the programs to work
in Windows 10.
